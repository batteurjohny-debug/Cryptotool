Code 26

Chaque lettre devient un nombre. A = 1, B = 2 … Z = 26.

Sans clé, le code reste le code classique A1Z26 (facile à casser par n'importe qui). Avec une clé, seul celui qui la connaît peut déchiffrer.

Les mots sont séparés par « / ». Les accents sont retirés (é devient e).

Ce code est un jeu d’apprentissage : n’importe qui peut le casser en quelques minutes. Le vrai chiffrement (AES) viendra dans une prochaine étape.
